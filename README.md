\# Heart Disease Classification



A machine learning application that predicts a heart disease classification

using patient health attributes. The project combines a Random Forest model,

FastAPI backend, Streamlit frontend, and Docker for deployment.



\## Features



\- Dataset exploration and preprocessing

\- Random Forest classification

\- Model evaluation using classification metrics

\- Saved model using Pickle

\- REST API built with FastAPI

\- Interactive frontend built with Streamlit

\- Dockerized frontend and backend using Docker Compose



\## Technologies Used



\- Python

\- Pandas

\- Scikit-learn

\- FastAPI

\- Streamlit

\- Docker

\- Docker Compose
